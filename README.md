# 朝日町たんけんマップ 🌅

福井県朝日町（越前市 朝日地区）の「おすすめスポット」を、自分で見つけて地図に追加していく自由研究プロジェクトです。

## できること

- 地図（OpenStreetMap）の上に、おすすめスポットをピンで表示
- 地図をクリックした場所を、そのままフォームに入力
- 名前・カテゴリー・おすすめポイントを入力してスポットを追加
- 追加したデータはブラウザに自動で保存される（閉じても消えない）
- 左のリストからスポットをクリックすると地図がそこに移動

## ファイルの中身

```
asahi-map/
├── index.html   … ページの骨組み
├── style.css    … 見た目（色・デザイン）
├── spots.js     … スポットのデータと、地図を動かすしくみ
└── README.md    … この説明書
```

`spots.js` の中の `STARTER_SPOTS` が、はじめに表示される「れい」のデータです。
ここを書きかえたり、画面のフォームからどんどん本物のスポットを追加していこう。

## VSCodeでの動かし方

1. このフォルダ（`asahi-map`）をVSCodeで開く
2. 拡張機能「**Live Server**」をインストール（まだの場合）
   - 左側の四角いアイコン（拡張機能）→ "Live Server" で検索 → Install
3. `index.html` を右クリック →「**Open with Live Server**」を選ぶ
4. ブラウザが開いて、地図が表示されたら成功！

> Live Serverを使わずに `index.html` をブラウザで直接開くだけでも一応動きます。

## GitHubで公開する（GitHub Pages）

自由研究として、みんなに見てもらえるURLを作ることもできます。

1. GitHubで新しいリポジトリを作る（例：`asahi-town-map`）
2. VSCodeのターミナルで、このフォルダから以下を実行

   ```bash
   git init
   git add .
   git commit -m "朝日町たんけんマップ 初回コミット"
   git branch -M main
   git remote add origin https://github.com/【あなたのユーザー名】/asahi-town-map.git
   git push -u origin main
   ```

3. GitHubのリポジトリページ →「Settings」→「Pages」
4. 「Branch」を `main` / `/(root)` にして「Save」
5. しばらく待つと `https://【ユーザー名】.github.io/asahi-town-map/` でアクセスできるようになる

## 地図の中心を自分の地域に合わせる

`spots.js` の一番上のほうにある、この部分を書きかえます。

```js
const MAP_CENTER = [35.903, 136.169]; // [緯度, 経度]
const MAP_ZOOM = 14;                  // 数字を大きくすると、より近くにズーム
```

緯度・経度は、Googleマップで場所を右クリックすると調べられます。

## 発表・提出のときのヒント

- 「なぜそのスポットを選んだのか」を `memo`（おすすめポイント）にしっかり書いておくと、後で自由研究のレポートにそのまま使えます
- カテゴリー分け（自然・歴史・食べ物・あそび場）ごとに、いくつずつ集まったか数えてグラフにしても面白いです
- 実際に行った日や、撮った写真の説明を書き足してもOK（`spots.js` の各データに好きな項目を増やせます）
